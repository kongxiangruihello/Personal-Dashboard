# 一隅 · Personal Dashboard

一个中文个人生活管理 Web App。以深蓝侧栏、青绿强调色和清晰的日程卡片，组织自己的计划、记录与目标。兼容桌面与手机浏览器，无第三方运行依赖。

## 第一版功能

- 生活概览：今日待办统计、周日历、快捷记录、最近笔记和目标进度。
- 计划：新增、编辑、删除待办与日程，日期、时间、优先级，完成状态与筛选。
- 记录：笔记、链接收藏，编辑与删除，仅允许 HTTP/HTTPS 收藏地址。
- 目标：总量、当前进度、单位、截止日期与下一步行动。
- 个人中心：昵称、签名、深色模式、JSON 备份导出与恢复、清空确认。
- 首次使用为空白个人空间，可在「个人中心 → 加载示例」体验示例内容。

## 本地运行

需要 Python 3。在项目目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8765 。静态源码在 `dist/`，无需构建或安装依赖。也可以将 `dist/` 交给任意静态托管服务。当前交付是源码仓库，尚未配置公网部署。

## 数据与边界

所有个人数据仅保存在当前浏览器当前站点的 localStorage。无注册、登录、服务器、跨设备同步或系统提醒。仓库只包含程序及虚构示例，不包含用户输入的数据。切换浏览器、域名或端口不会迁移数据；清理浏览器可能删除数据，建议定期导出备份。本地存储没有额外加密，不应把本 App 当作密码保险箱。

备份恢复会验证数据结构及收藏链接协议，再确认覆盖。单文件上限 5 MB。无效备份不会覆盖当前记录。存储写入失败时显示提示并保留原状态。

## 结构

- `dist/index.html` — 页面入口与元数据
- `dist/style.css` — 响应式样式与深色主题
- `dist/app.js` — 界面、表单、状态与备份校验
- `.openai/hosting.json` — 可选静态托管目录配置，无已注册站点

使用浏览器原生表单、dialog 和 progress 控件。支持 WebMCP 的浏览器可使用只读 `read_life_overview` 工具；不支持时自动忽略。

## 后续可扩展
